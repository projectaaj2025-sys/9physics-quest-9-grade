# Руководство по участию в проекте (Contributing)

Мы рады любому вкладу в развитие образовательного проекта **«Физика-Квест: Орбита-9 — Щит Земли»**!

Проект создан для помощи школьникам, учителям и любителям физики. Вы можете помочь сделать его ещё лучше: добавить новые интересные задачи, улучшить формулировки, исправить опечатки или предложить новые переводы.

---

## 💡 Чем вы можете помочь?

1. **База вопросов и задач**:
   - Предложить новые задачи для параграфов 9 класса.
   - Добавить интересные качественные вопросы, расчётные задачи или интерактивные сопоставления.
   - Проверить точность физических определений, числовых значений и формул.

2. **Локализация и языки**:
   - Улучшение перевода на казахский язык (Қазақ тілі).
   - Улучшение перевода на английский язык (English).
   - Добавление переводов на другие языки (например, узбекский, кыргызский и др.).

3. **Игровой процесс и дизайн**:
   - Предложения по улучшению баланса игры (скорость астероидов, запас энергии, щиты).
   - Улучшение адаптивности для мобильных устройств и планшетов.
   - Новые визуальные эффекты на Canvas или стили космического корабля.

4. **Режим учителя**:
   - Шаблоны домашних заданий и проверочных работ.
   - Улучшение функционала экспорта и аналитики.

## 🛠 Как предложить изменения (Pull Request)

1. **Сделайте форк (Fork)** репозитория в свой аккаунт GitHub.
2. **Клонируйте** форк на свой компьютер:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/physics-quest-9-grade.git
   cd physics-quest-9-grade
   ```
3. **Создайте ветку** для ваших изменений:
   ```bash
   git checkout -b feature/new-physics-questions
   ```
4. **Внесите изменения** в файл `index.html` (или сопутствующие файлы).
5. **Проверьте работу** в браузере:
   - Откройте `index.html` локально.
   - Убедитесь, что нет ошибок в консоли браузера (клавиша `F12` -> вкладка `Console`).
   - Проверьте сохранение прогресса и корректность отображения формул.
6. **Закоммитьте изменения**:
   ```bash
   git add index.html
   git commit -m "Добавлены новые вопросы по теме Законы Ньютона"
   ```
7. **Отправьте ветку** в свой репозиторий:
   ```bash
   git push origin feature/new-physics-questions
   ```
8. **Создайте Pull Request** на GitHub со ссылкой на оригинальный репозиторий.

## 🐛 Сообщения об ошибках (Issues)

Если вы заметили неточность в задаче или баг в игре, создайте issue в разделе **Issues**:
- Укажите номер уровня / параграфа.
- Приведите правильную формулировку или расчёт.
- Если проблема в отображении — прикрепите скриншот и укажите браузер/устройство.

Спасибо за поддержку качественного школьного физического образования! 🚀

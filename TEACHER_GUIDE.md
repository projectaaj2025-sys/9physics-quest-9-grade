# Гайд для учителя — Физика-Квест: Орбита-9

## 1. Быстрый старт (5 минут)

1. Откройте `index.html` или сайт GitHub Pages
2. Нажмите **Режим учителя**
3. Вкладки:

### Вкладка «Создать задание»
- **Тип задания:** выберите из 7 типов
- **Урок (тема):** привяжите к параграфу §1-§43 или к своему уроку
- **Сложность:** лёгкий/средний/сложный (влияет на очки)
- **Вопрос RU/EN/KK:** обязательно RU, остальное — для мультиязычности
- **Формула:** например `v = v0 + at`
- **Ответы:** зависят от типа

Типы ответов:
- **multiple-choice:** 4 варианта, укажите индекс правильного (0-3)
- **multi-select:** несколько правильных
- **matching:** две колонки (левая/правая) + правильные пары
- **short-answer:** слово или список синонимов (через `;`)
- **numeric:** число + допуск (например 9.8 ±0.2)
- **true-false:** true/false
- **fill-blank:** слово для пропуска

### Вкладка «Мои уроки»
- Добавьте свой урок: например `§44. Квантовая физика — введение`
- Введите название на 3 языках (если EN/KK пусто — возьмётся RU)
- После создания урок появится в выборе уровня и в списке тем

### Вкладка «Назначения» — главное для работы с классом

#### Классы
1. Введите название класса: `9А`
2. В поле ученики — по одному в строке:
```
Айдана
Данияр | player_a1b2c3
Меруерт
```
Формат `Имя | playerId` нужен если в классе два ученика с одинаковым именем. ID ученик берёт в **Профиль → Идентификатор игрока**.

3. Сохраните класс
4. Выберите класс + урок для всего класса + комментарий (например «до пятницы») → **Назначить всему классу**

#### Индивидуальные назначения
- Имя ученика: `Айдана`
- ID (необязательно)
- Уровень: выберите §
- Комментарий
- Назначить

Ученик увидит это во вкладке **Назначено тебе** на экране выбора уровня, если его имя в профиле совпадёт.

#### Коды результатов
- Ученик после победы видит блок **Код результата для учителя** → копирует
- Учитель вставляет в поле **Код результата ученика** → **Добавить результат**
- Результат попадает в общий журнал (вкладка Статистика / Рекорды)

Экспорт/Импорт назначений — для переноса между устройствами (JSON).

### Вкладка «Мои задания»
- Список всех созданных вами заданий
- Можно удалить

### Вкладка «Статистика»
- Всего решено, верных, точность, лучший счёт
- По темам и типам заданий

## 2. Сценарии использования

### Сценарий 1: Домашка
1. Создайте класс 9А
2. Назначьте §5 всему классу
3. Попросите учеников пройти и прислать коды
4. Импортируйте коды → проверьте журнал

### Сценарий 2: Контрольная
1. Создайте свой урок «Контрольная №1»
2. Добавьте 15 заданий разного типа, привяжите к этому уроку
3. Назначьте урок классу
4. Ученики проходят только ваши задания (база + ваши)

### Сценарий 3: Проектная работа
- Ученики сами создают задания в режиме учителя (на своём устройстве) и экспортируют JSON → присылают вам → вы импортируете

## 3. Где хранятся данные?

Всё в `localStorage` браузера:
- `pq9_settings` — профиль, язык, дизайн ракеты
- `pq9_progress` — пройденные уровни, звёзды
- `pq9_custom_tasks` — задания учителя
- `pq9_custom_lessons` — уроки учителя
- `pq9_assignments` — назначения
- `pq9_classes` — классы
- `pq9_records`, `pq9_history` — рекорды

**Важно:** если ученик очистит кэш браузера — прогресс пропадёт. Рекомендуйте делать экспорт.

## 4. Советы

- Для демо на уроке используйте проектор и один ноутбук — дети видят, как играть
- Начните с бонусного уровня ТБ — там простые вопросы
- Используйте теорию перед уровнем — она экономит время на объяснение
- PDF-конспект — раздайте ученикам для подготовки

## 5. FAQ

**Q: Ученик не видит назначение?**
A: Проверьте, чтобы имя в профиле ученика ТОЧНО совпадало с именем в назначении (регистр не важен, пробелы обрезаются). Лучше используйте ID.

**Q: Можно ли поставить оценку автоматически?**
A: Сейчас — звёзды (1-3) по точности. 90%+ = 3 звезды = 5, 70%+ = 2 звезды = 4, остальное = 3. Вы можете конвертировать сами.

**Q: Как удалить все назначения?**
A: Вкладка Назначения → у каждого есть крестик. Или очистите localStorage: F12 → Application → Local Storage → удалить ключи pq9_*

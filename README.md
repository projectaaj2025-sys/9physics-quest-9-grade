# Физика-Квест: Орбита-9 🚀 (9 класс)

Образовательная RPG-игра по физике 9 класса (учебник Н.А. Закировой, Ашировой).
Ученик управляет кораблём, защищает город от астероидов и отвечает на вопросы
по физике, чтобы активировать щит. Обучение встроено в игровой процесс.

## Как играть

Проект — **один самодостаточный файл** `index.html` (все стили, скрипты,
задания, сюжет и даже PDF-конспекты встроены внутрь). Никаких зависимостей,
сборки и сервера не требуется.

- **Локально:** просто откройте `index.html` двойным кликом в браузере.
- **Онлайн:** выложите на GitHub Pages / Netlify / любой статический хостинг.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы (см. ниже).
2. Откройте **Settings → Pages**.
3. В разделе *Build and deployment* выберите **Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через пару минут игра будет доступна по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Возможности

- 🎮 **48 уровней:** техника безопасности, 43 параграфа (§1–§43), 4 лабораторные работы.
- 🛡 **Геймплей:** корабль отражает астероиды щитом, щит заряжается за правильные ответы и энергетические сферы.
- 📝 **7 типов заданий:** тест, множественный выбор, сопоставление, краткий и числовой ответ, верно/неверно, пропуск.
- 👩‍🏫 **Режим учителя:** создание собственных заданий и уроков, назначение уровней ученикам, классы, статистика, журнал результатов, импорт/экспорт.
- 📖 **Теория перед уровнем** + полный конспект всех параграфов (в т.ч. скачиваемый PDF).
- 🌍 **Три языка:** русский, английский, казахский.
- 📱 **Мобильное управление:** сенсорные кнопки + ведение корабля пальцем по экрану.
- 🏆 Рекорды, история прохождений, профиль пилота с выбором дизайна ракеты.
- 📊 Прогресс хранится локально в браузере (localStorage).

## Управление

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| Движение | `W A S D` или `← ↑ ↓ →` | Экранные кнопки / вести пальцем по полю |
| Пауза | `P` | Кнопка ⏸ |

**Ведение пальцем:** коснитесь любой точки игрового поля и ведите пальцем —
корабль повторяет движение (относительное управление, палец не закрывает
корабль). Чувствительность настраивается константой `DRAG_SENS` в секции
`setupTouchControls` внутри `index.html` (сейчас `1.0` — движение 1 в 1).

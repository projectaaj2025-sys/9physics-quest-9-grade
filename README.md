Интерактивная сюжетная образовательная RPG-игра по курсу физики 9 класса (по программе учебника **Н.А. Закировой и Р. Аширова**). 

Игрок выступает в роли пилота защитного корабля орбитальной станции «Орбита-9». Отражая астероидную угрозу с помощью энергетических щитов и защитного купола земного города, ученик решает физические задачи, выполняет виртуальные лабораторные работы и осваивает все разделы школьного курса физики.

## 🌐 Как играть онлайн через GitHub Pages

Проект полностью готов к мгновенному хостингу на **GitHub Pages** без сборки и компиляции:

1. Выгрузите проект в репозиторий GitHub (инструкция ниже).
2. Перейдите в настройки репозитория: **Settings** → **Pages**.
3. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch` (или используйте встроенный GitHub Action `GitHub Actions`).
   - **Branch**: выберите `main` (или `master`), папку `/(root)`, нажмите **Save**.
4. Через 30–60 секунд игра станет доступна по адресу:
   ```
   https://<ВАШ_GITHUB_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/
   ```

## 🚀 Быстрый запуск на компьютере (офлайн)

Проект абсолютно автономен: ему не требуются интернет, Node.js, веб-сервер или установка библиотек.

- **Способ 1:** Просто дважды кликните по файлу `index.html` — игра запустится в любом современном браузере (Chrome, Firefox, Safari, Edge, Яндекс.Браузер).
- **Способ 2 (для разработчиков):** Запустите локальный сервер:
  ```bash
  # Python 3
  python3 -m http.server 8000

  # или через npx
  npx serve .
  ```
  и откройте в браузере `http://localhost:8000`.

## 📤 Инструкция по выгрузке на GitHub

### Вариант А. Через скрипт автоматической выгрузки (самый простой)

В корне архива подготовлены скрипты:
- **Для Linux / macOS:** запустите терминал в папке проекта и выполните:
  ```bash
  ./upload-to-github.sh
  ```
- **Для Windows:** дважды кликните по файлу `upload-to-github.bat`.

Скрипт сам инициализирует Git, сделает коммит и предложит ввести ссылку на созданный репозиторий на GitHub.

   ```bash
   git init

   git remote add origin https://github.com/<ВАШ_ЛОГИН>/physics-quest-9-grade.git
   ```

## 🕹 Особенности игры и механики

- **Сюжетная кампания из 48 уровней:**
  - Вводный уровень: техника безопасности в кабинете физики.
  - 43 параграфа теории и задач по учебнику.
  - 4 интерактивные лабораторные работы.
- **Интерактивный геймплей:**
  - Движение корабля по горизонтали (клавиатура, мышь, тач-джойстик).
  - Энергетический щит корабля: отбивание астероидов, физика отскока.
  - Энергетический купол: защита города от повреждений.
  - Сбор энергосфер для зарядки защитных систем.
- **7 типов учебных заданий:**
  1. *Тест* с выбором одного верного ответа.
  2. *Множественный выбор* (выбор нескольких верных утверждений).
  3. *Сопоставление* физических понятий, формул и единиц измерения.
  4. *Расчётные задачи* (числовой ответ с указанием единиц в СИ).
  5. *Текстовый ввод* ключевых терминов и определений.
  6. *Верно / Неверно* (быстрая проверка понимания физических законов).
  7. *Заполнение пропусков* в формулах и законах.
- **RPG-система:**
  - Профиль пилота, уровни и звания (Кадет → Лейтенант → Капитан → Командор).
  - Разблокировка новых дизайнов космического корабля.
  - Подробная статистика: точность ответов, время прохождения, уничтоженные астероиды.
- **👨‍🏫 Полнофункциональный режим учителя:**
  - Создание классов и распределение учеников.
  - Назначение индивидуальных и классных домашних заданий.
  - Встроенный редактор заданий: добавление авторских задач с формулами и подсказками.
  - Экспорт и импорт базы заданий и прогресса в формате JSON.
- **🌍 Полная трёхъязычность:**
  - Русский язык
  - Қазақ тілі (казахский)
  - English (английский)
  - Переключение в 1 клик прямо во время игры.
- **📱 Поддержка всех устройств:**
  - Компьютеры и ноутбуки (клавиатура WASD / стрелки, пробел).
  - Планшеты и интерактивные доски.
  - Смартфоны (виртуальный наэкранный джойстик и сенсорные кнопки).
- **🔊 Синтезатор звука на Web Audio API:**
  - Все звуковые эффекты (лазеры, взрывы, щиты, правильные/неправильные ответы) генерируются процедурно. Никаких тяжёлых аудиофайлов!
- **💾 Сохранение в LocalStorage:**
  - Прогресс сохраняется автоматически в браузере.

## ⚙️ Управление в игре

- **Влево / Вправо:** Клавиши `A` / `D` или стрелки `←` / `→` на клавиатуре.
- **Активация щита:** Клавиша `Пробел` или кнопка **«Щит»** на экране.
- **Пауза:** Клавиша `Escape` или кнопка паузы в углу.
- **Мобильное управление:** Виртуальный аналоговый джойстик слева + кнопка щита справа.
- **Ответ на задания:** Клик мыши или нажатие по вариантам / ввод значений с клавиатуры.

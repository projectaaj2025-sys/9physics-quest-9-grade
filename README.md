## 🚀 Что это?

Игра в жанре **космического шутера + викторины**:

- Игрок управляет ракетой, защищает город-купол от астероидов
- Каждые 3 астероида или ~15 секунд — вопрос по физике из текущего параграфа
- Правильный ответ = энергия щита + восстановление города + очки
- Неправильный = урон городу
- Цель уровня — ответить на все вопросы параграфа

### Сюжет «Орбита-9»

Земля в 2147 году. Орбитальная станция «Орбита-9» — последний щит. 7 эпизодов, связанных с темами 9 класса: кинематика, динамика, энергия, колебания, электромагнитные явления, атомное ядро.

### Уровни (48)

- **§0 — Бонус:** Техника безопасности (20 вопросов)
- **§1-§43 — Параграфы учебника:** 
  - Кинематика (§1-§10), Динамика (§11-§18), Законы сохранения (§19-§23), Колебания и волны (§24-§32), Электромагнитное поле (§33-§38), Строение атома (§39-§43)
- **Лабораторные (4):** исследование равноускоренного движения, пружинный маятник и т.д.
- **Уроки учителя:** кастомные уровни, созданные в режиме учителя

## 🎮 Особенности

- ✅ **Один HTML-файл** — работает без сервера, просто открыть `index.html`
- ✅ **3 языка:** Русский / English / Қазақша
- ✅ **РПГ-профиль пилота:** имя + 20 дизайнов ракет (Темірқазық, Сүмбіле, Жеті қарақшы, Орион, Бүркіт, Тұлпар и др.)
- ✅ **Теория перед уровнем:** краткая теория + конспект + эксперименты с ссылками
- ✅ **Полный конспект всех 43 параграфов** — в модальном окне и PDF-генерация
- ✅ **Режим учителя:**
  - Создание заданий (7 типов: тест, мульти-выбор, сопоставление, краткий ответ, числовой, верно/неверно, пропуск)
  - Свои уроки
  - Назначение уровней ученикам (по имени или ID) + классы
  - Импорт/экспорт назначений
  - Коды результатов учеников → журнал учителя
- ✅ **Рекорды и история прохождений** (localStorage)
- ✅ **Адаптивность:** телефон, планшет, ПК + сенсорный джойстик
- ✅ **Офлайн:** всё в localStorage, без бэкенда

## 👩‍🏫 Режим учителя — быстро

1. В игре нажми **Режим учителя**
2. Вкладка **Создать задание** → выбери тип, урок, введи вопрос
3. Вкладка **Мои уроки** → добавь свой урок (например §44)
4. Вкладка **Назначения** → введи имя ученика + выбери уровень
5. Ученик в своем профиле указывает то же имя → видит вкладку «Назначено тебе»
6. После прохождения ученик копирует **Код результата** и отправляет учителю
7. Учитель вставляет код в **Назначения → Код результата ученика** → результат попадает в журнал

## 🧪 Типы заданий

| Тип | Описание | Пример |
|-----|----------|--------|
| multiple-choice | Один правильный ответ | Что такое инерция? |
| multi-select | Несколько правильных | Выберите векторные величины |
| matching | Сопоставление | Формула ↔ Название |
| short-answer | Слово | Единица измерения силы? |
| numeric | Число с допуском | g = ? м/с² |
| true-false | Верно/Неверно | Инерция — свойство тела? |
| fill-blank | Пропуск | F = m * ___ |
